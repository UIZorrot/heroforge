# Judge access instructions

Live Monad Testnet prototype: https://hf.txzy.net/monad/

No HeroForge email login is required for the mint page. Please use a browser with an injected EVM wallet such as MetaMask. The page requests Monad Testnet, chain ID 10143. A small amount of test MON is needed to pay transaction gas; the contract does not charge a mint fee.

Choose one of the four default illustrated heroes, set an ASCII card name and battle-power snapshot, connect the wallet, and select “Mint hero card.” Confirm the transaction in the wallet. After confirmation, the page displays a transaction link and reads your cards directly from the contract. Reload and reconnect to check that ownership persists.

This prototype is a collectible ownership and minting flow. Game combat remains offchain. NFT ownership does not yet authorize game-account card ownership or battle stats. Direct file upload, IPFS pinning, NFT marketplace trading and onchain battle settlement are not implemented in this release.
