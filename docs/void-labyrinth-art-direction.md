# Void Labyrinth：场景与敌人美术

更新：2026-10-13。当前代码已接入敌人卡牌与3D场景；怪物继续保持卡牌形态。主题音频、六类房间的完整环境包和三档腐化层仍未实现。

## 视觉与语言

玩家界面使用英文，与现有 Forge / Vault / Arena 一致；玩家上传的肖像与自行生成的名字、技能不翻译。以黑石、残金、骨白、磨损羊皮纸与烛光形成同一世界，保留现有 Cormorant Garamond 标题字和细金线。虚空表现为缺失、消失的名字和被封住的空间，避免把所有怪物都变成人形黑影。

入口为三座门户，与 The Fading Lantern（1000 BP）、Hall of Reflections（5000 BP）、The Lightless Heart（10000 BP）对应。默认远景为暗淡天空与薄雾，真实3D前景负责空间表现：断裂石桥、悬空地台、残缺门户、破碎环形结构、石柱、碎片与路径符文。门户中的怪物为有薄边框与厚度的卡牌，继续使用原肖像。日蚀环境绘图保留为可选概念稿与WebGL降级插画，不作为正常3D入口的背景。

切换档位改变门户受光与镜头；窄屏镜头聚焦所选门户。鼠标视差、漂浮尘埃和符文呼吸只承担空间表现，操作由可键盘访问的 DOM 按钮负责。场景按需加载，DPR 上限1.25，连续渲染限制约30fps；离屏与后台暂停。减少动态时静态渲染，WebGL/资源加载不可用时保留可用的环境插画与操作。

## 验收与边界

自动检查覆盖图鉴角色与运行时一致、九张运行时肖像/环境文件齐全、旧NPC文案恢复时规则与玩家内容不变、战斗事件和单次费用不被表现层改写。浏览器检查英文入口、真实3D画布、三档选择、图鉴切换、四人上限、BP合计、重复站位反馈及390px窄屏。

怪物明确保持生成绘画卡牌，不推进角色骨骼模型。三个门户的基本结构共享，完整腐化差异、六类房间、音频和卡牌上的Boss预告标记继续按[一期策划](pve-void-labyrinth-v1.md)推进。实际冒险仍需live服务；mock支持美术、档位与编队预览，不能记作真人通关验收。

## 暗天空下的悬空圣所（已实现的环境迭代）

整体曝光与环境填光降低，冷色背光照出断面，门户上方的小型悬灯与地台灯火提供暖色局部落光。石材采用倒角、凹凸纹理与粗糙表面，细金属嵌线承接高光。半透明shader平面表现柔和光束与分层薄雾；它们是轻量环境效果，不是体积光线追踪。石桥与地台之间有真实空隙，建筑碎片与残缺环结构缓慢悬浮，背景留白凸显距离与轮廓。

静态建筑按材质及阴影属性合批，动画卡牌、碎片和透明雾层独立绘制；一张1024阴影贴图按250ms更新，DPR封顶1.25。离屏/后台仍暂停，减少动态使用固定姿态，退出时释放几何、材质、贴图与监听器。实际硬件30fps仍是验收目标，不能由渲染限频推断已经达标。

新增[日蚀远景完整生成提示词](art/void-labyrinth-environment-v3.prompt.json)，PNG与WebP均保留在项目美术目录。该远景用于概念参考/降级；默认实时场景使用暗天空。栏目、章节、怪物名字、三档BP与战斗规则保持原有定义。

本轮验收：正常入口为暗天空而非远景插画；桌面及390px确认真实Three画布、三档选择与单画布重入，控制台无页面错误。合批后一次桌面采样主绘制95次、含阴影采样162次；这不是设备帧率基准。减少动态的固定姿态与停止连续渲染经代码检查；本轮没有切换操作系统动态偏好。TypeScript、定向lint与Vite生产构建检查通过，战斗规则没有改动。
