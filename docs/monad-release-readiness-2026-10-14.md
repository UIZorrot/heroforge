## 已完成

新钱包默认一次赠送 **500 Dust**，当前每次锻造 **100 Dust**，可支付四次成功锻造并剩余 100。配置保护保证初始余额至少为四次实际锻造费用；重新登录不补发，已有钱包不重置。新账号同时获得八名初始英雄，其标称 BP 和按战斗属性成本加权的初始预算均为 1000。

Chronicle 使用十层虚空迷宫，包含战斗、战后选择、事件、交易和营地。每次战斗先在棋盘布阵并确认；出战为 1–4 人，按团队总 BP 的 ±5% 检查 1000 / 5000 / 10000 三档。首通 Dust、钱包流水和完成记录一起提交，重试回滚检查点资源与奖励。

锻造英雄与生成记录在同一事务保存。存储失败回滚并退款；已完成保存后读取钱包摘要失败，不会误退费用。后端安装清单补齐了锻造所需 SDK。

初始肖像、怪物与场景卡面使用固定素材版本参数，解决 CDN 把旧占位 HTML 缓存为图片的问题。公共编译资源使用独立发行目录。用户上传图片、保存的卡牌数据和已有 NFT 元数据没有改写；独立 `/monad/` 的原构建和素材保留。
